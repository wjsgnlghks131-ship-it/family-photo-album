# 🏡 우리 가족 앨범 (Our Family Memories)

> **스마트폰과 PC에서 가족 누구나 사진을 올리고, 사진 아래 댓글과 마음을 남길 수 있는 따뜻한 가족 전용 웹 앨범입니다.**

---

## 🌟 주요 기능

1. **📱 스마트폰 완벽 최적화 (Mobile-First)**
   - 스마트폰 화면에 꼭 맞는 반응형 웹 인터페이스
   - 화면 하단 플로팅 사진 올리기(FAB) 버튼
   - 터치 친화적 카드 스크롤 및 고해상도 전체화면 뷰어(Lightbox)

2. **📅 월별 & 날짜별 보기 (Core Feature)**
   - **월별 가로 스크롤 탭**: `2026년 9월 (2장)`, `2026년 8월 (2장)` 등 원하는 월을 원클릭으로 필터링
   - **날짜별 타임라인 그룹핑**: `2026년 9월 8일 (화요일)`과 같이 날짜별로 묶어서 일기처럼 보기
   - **3가지 보기 모드 지원**:
     - 📱 **타임라인 피드**: 인스타그램/스토리 피드처럼 큰 사진과 댓글을 한눈에 감상
     - 🖼️ **앨범 갤러리**: 콤팩트한 그리드로 날짜별 사진 모아보기
     - 📅 **달력 날짜별**: 달력 일자 칸에 당일 찍은 사진 썸네일 표시 & 날짜 터치 시 당일 사진 모아보기

3. **📸 간편한 사진 업로드**
   - 스마트폰 카메라 촬영 또는 갤러리 사진 선택
   - 가족 구성원 뱃지 원클릭 선택 (아빠 👨, 엄마 👩, 딸 👧, 아들 👦, 할머니 👵, 할아버지 👴 등)
   - 사진 찍은 날짜 지정 (기본 오늘 날짜) 및 이야기/에피소드 입력
   - 모바일 데이터 절약 및 초고속 업로드를 위한 클라이언트 자동 이미지 압축

4. **💬 사진별 코멘트(댓글) & 따뜻한 공감**
   - 사진 바로 아래 가족들의 댓글 타임라인 및 시간 표시 (`방금 전`, `1시간 전`)
   - 한 번의 터치로 입력되는 이모지 빠른 리액션 (`❤️`, `👏`, `🥰`, `🥳`, `🍕` 등)
   - 두근두근 하트 좋아요 카운터

5. **📲 스마트폰 간편 접속 (QR 코드)**
   - 상단 **"스마트폰 접속"** 버튼을 누르면 화면에 접속용 QR 코드가 바로 표시됩니다.
   - 같은 집 와이파이(Wi-Fi)에 연결된 스마트폰 카메라로 QR만 비추면 바로 앨범 사이트가 열립니다!

## 🚀 실행 방법

### 방법 1 (가장 간단):
- `d:\테스트\가족앨범_실행하기.bat` 또는 `d:\테스트\만드는 사이트\start.bat` 파일을 **더블 클릭**합니다.
- 자동으로 브라우저가 열리며 웹사이트가 실행됩니다!

### 방법 2 (터미널 명령):
```bash
cd "d:\테스트\만드는 사이트"
npm start
```
- 브라우저에서 `http://localhost:3000` 접속

---

## 📱 온 가족 스마트폰에서 접속하는 방법

1. 컴퓨터와 스마트폰이 **같은 집 와이파이(Wi-Fi)**에 연결되어 있는지 확인합니다.
2. 컴퓨터 화면 상단 오른쪽의 **[스마트폰 접속]** 버튼(QR 아이콘)을 누릅니다.
3. 스마트폰 기본 카메라 앱을 켜고 컴퓨터 화면의 QR 코드를 비춥니다.
4. 스마트폰 화면에 뜨는 주소 링크를 누르면 스마트폰에서 바로 가족 앨범이 실행됩니다.
5. (팁) 스마트폰 브라우저 메뉴에서 **"홈 화면에 추가"**를 누르면 스마트폰 앱처럼 사용할 수 있습니다!
